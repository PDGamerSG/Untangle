Why is the code like this?

Untangle reads a repository’s commits, reviews, issues, docs and handover calls, then answers with the evidence behind each decision.

Follow a question Open Untangle

The examples on this page are real Untangle output for knadh/listmonk, an open-source newsletter manager.

Scroll to pull the thread

Every codebase is a knot.

The reason a value is 10 lives in a commit from 2020, a review thread, an incident ticket, and a call where someone explained it once. The person who knew may have left.

In listmonk alone, 2,270 commits, 896 pull requests and 2,284 issues hold 2,546 recorded decisions.

        Run it on your own repository.

        Open source under the MIT license. The default answer path is deterministic and works without a model key. A model can improve the wording, but it can’t add uncited claims.

        1. Ingest a repository

          Git history, GitHub discussions, docs, symbols, config changes and dependencies go into a Neo4j graph.

        2. Ask a question

          The router resolves the entity you named and retrieves its decision chain and evidence.

        3. Review the path

          Read the answer with its citations, the supersession timeline, a confidence score and the person to ask.
